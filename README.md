# Transformation Tracker (PWA)

A responsive Progressive Web App (PWA) built with vanilla JavaScript and Supabase, designed to track daily progress with offline capabilities and secure authentication.

## Features

- **Secure Authentication:** User sign-up, login, and email verification powered by Supabase Auth.
- **PWA Ready:** Installable on mobile and desktop devices with offline support and a native app-like experience.
- **Fast Deployment:** Continuous deployment and automatic builds configured via Vercel.

## Tech Stack

- **Frontend:** HTML5, CSS3, Vanilla JavaScript
- **Backend & Auth:** Supabase
- **Hosting & CI/CD:** Vercel, GitHub

## Getting Started Locally

To run this project locally on your machine:

1. **Clone the repository:**
   ```
   git clone https://github.com/obiagufaith3-sys/transformation-tracker.git
   ```
2. **Open the project in your code editor (e.g., VS Code).**

3. **Set Up Supabase:**

-Create a free account on Supabase.

-Create a new project and get your Project URL and Anon/Public Key from your project settings.

-Add your credentials into your project configuration file where required.

4. **Run a local server: Open index.html using a tool like the Live Server extension in VS Code to launch the app.**
